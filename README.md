# AI_Project_2
Для запуска интерфейса бота медицинской помощи нужно:
1. Установить все файлы на компьютер.
2. Через терминал установить requirements для корректной работы кода.
3. Чтобы запустить интерфейс в окне браузера, нужно прописать в терминал вашей IDE команду: python -m streamlit run main.py

Для удобства работы с кодом было оставлено большое количество комментариев. По доп. вопросам пишите в конфу ТГ.
